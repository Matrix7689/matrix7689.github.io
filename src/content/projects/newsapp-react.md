A responsive website built with React and Node.js that shows the latest news by category from the New York Times and Guardian APIs. Built Mar–May 2020.

- Share any article through Facebook, X/Twitter or email.
- Bookmark articles; bookmarks are saved locally in the browser with `localStorage`.
- Search news by keyword with an asynchronous search box that autosuggests as you type.
